How I build with AI

my working rules ↘

  • Let agents fetch their own context.

    Through tools like an MCP server, instead of people pasting it into a chat window.

  • Hand the agent a real workflow.

    The agents I've built do admin work on the product's own services. A chat box is optional.

  • Put a number on it before calling it done.

    Hours saved, detection accuracy, efficiency gained: if it can't be measured, it isn't finished.

  • AI sits on a backend that already has to stay up.

    TDD, tracing and on-call habits from years of backend work come with me into every LLM feature.
